# UI 階段二：操作流程與狀態回饋

## 範圍

本次更新 Conference 應用程式的操作回饋，不更動模型、權重、特徵相容性 key、
Gallery 結構、辨識門檻、取樣規則或安裝依賴。既有特徵與來源點雲不需要遷移
或重新註冊；Journal 工作目錄不受影響。

## 啟動前檢查

即時頁側欄新增來源、模型／權重、人物偵測器、相容 Gallery、註冊人物及設定摘要。
缺少檔案、未填人物資訊、同 ID 名稱衝突或無效數值時，Start 停用；
修正輸入後會重新判斷。

「檔案存在」不等於模型已載入成功，也不表示裝置已可使用。每次啟動仍由擷取
工作在背景檢查並開啟 Azure Kinect；獨立的設備檢查也改在背景執行。
SAM 的 UI 檢查只確認路徑，完整 SHA256 安全驗證仍由背景偵測器在載入前執行。

即時模式沒有相容 Gallery 時仍可啟動前景預覽，但無法辨識人物。註冊不需要
先有 Gallery。離線辨識則在編碼前檢查可用 Gallery。相容性仍依既有模型、
權重、T 與前處理契約判定，不把其他模型的特徵混入。

## 即時狀態

- 明確區分開啟來源、載入模型、等待人物、累積影格、等待穩定、未知人物與
  沒有相容 Gallery。嚴格模式多人與點數不足也分開顯示。
- 當前沒有有效人物時，不把先前的候選結果當成新的辨識結果顯示。
- 進度條代表目前影格緩衝的填入程度，不是信心值、準確率或整個工作的完成度。
  相似度、分差與穩定窗口仍來自原本辨識流程。
- 高度有限時保持 RGB 與點雲左右並列，只有垂直空間足夠時才改成上下排列。
- 啟動、執行、停止與待檢視期間鎖定擷取設定。停止在背景執行，確定擷取
  執行緒退出後才釋放控制項，不提前顯示設備已可重用。
- 中英文切換不修改人物名稱或操作狀態。原始診斷與第三方錯誤可能保留原語言。

## 引導式註冊

1. 填寫人物並啟動 session。來源開始供應影格且模型載入完成後，才開放 Start pass。
2. Start pass 是「送出開始要求」。有效人物通過暖機後才真正擷取；尚未偵測到
   有效人物時不代表按鈕失效。重複點擊不會建立重複要求。
3. End／Discard 等待擷取工作確認後，才再次開放 Start pass。
   Finish & review 則停止擷取並進入檢視。
4. 檢視視窗顯示選取片段與候選特徵數。沒有選取時不能儲存；
   關閉再開啟會保留本次執行期間的選取狀態。
5. 儲存期間鎖定檢視操作並顯示進行中；既有 commit 成功後才更新 Gallery。
   若儲存失敗，保留檢視供修正或重試。繼續擷取會保留已有片段。

右側的「準備／擷取／檢視／儲存」標示當前階段。Stop 是取消擷取，
不等於 Finish & review，也不會替代 Commit。待檢視 session 須先儲存、
繼續擷取或放棄，才能開始另一個 session。

## 批次工作

多模型來源註冊分成「各模型結果」與「執行紀錄」，另有目前工作狀態列。
完成時逐模型顯示註冊、略過或未儲存與新增特徵數；取消、失敗不會顯示成功。
原本全部模型完成後才提交的交易保護不變。

Gallery／來源移轉分開顯示驗證資料包、打包與匯入。既有衝突預覽、
人工確認、備份及取消機制保留。來源處理顯示實際回報的幀數；
沒有可靠總量的階段維持不定量進度，不估算假百分比。

## Local 驗收

建議使用獨立測試 clone，先備份資料。

- 在 980x640、最大化與 Windows 縮放下切換中英文。
- 測試空人物名稱、不存在的 Replay／偵測器路徑，再恢復正確設定；
  確認摘要說明原因、Start 可以恢復。
- 空 Gallery 時測試即時預覽，不應接受任何人物；註冊或匯入相容特徵後再辨識。
- Kinect 未連接時測試啟動與設備檢查，確認 UI 可回應；連接後重試。
- 完整操作等待人物、暖機、Start／End／Discard、檢視、繼續擷取、儲存及放棄；
  擷取與停止期間切換語言。
- 檢視時取消全部勾選，關閉再開啟，確認不會自動勾回。
  正常儲存後檢查 Gallery 人數與特徵數。
- 以測試人物執行多模型註冊、來源／Gallery 移轉，核對結果摘要、
  取消、重複資料與衝突確認。
- 設備檢查／停止尚未完成時，確認其他頁面不能搶用設備。

自動測試：

```bash
python -m unittest discover -s mph_gait_id/tests -q
python -m unittest discover -s scripts/tests -q
python scripts/validate_release.py
```

GUI 測試需圖形顯示環境。Server 測試使用暫存資料庫與模擬擷取工作，不代替
Windows／Azure Kinect 實機驗證。若底層 SDK 未返回，介面會維持停止中，
不會假定裝置已釋放。
