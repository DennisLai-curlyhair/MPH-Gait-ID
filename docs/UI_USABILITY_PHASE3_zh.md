# UI 階段三：版面偏好與清單操作

## 範圍

本次為 Conference 應用程式的 Tkinter/ttk 介面優化。
不更動模型、權重、推論參數、辨識門檻、Gallery schema、相容性 key 或套件依賴。
既有 Gallery 與來源點雲不需要遷移或重新註冊。

## 版面記憶

正常關閉程式時保存視窗大小／位置、主要分隔比例、表格欄寬與設定區域的收合狀態。
語言沿用原本的保存機制。語言選擇旁的圓形箭頭為「恢復預設版面」，需確認後
才重設；模型、T、threshold、人物及執行中的工作不會被重設。

版面檔 `settings_layout.json` 與既有 `settings.json` 放在同一個本機設定目錄：

| 平台 | 預設目錄 |
|---|---|
| Windows | `%APPDATA%/mph_gait_id/` |
| Linux | `$XDG_CONFIG_HOME/mph_gait_id/`，未設定時為 `~/.config/mph_gait_id/` |
| macOS | `~/Library/Application Support/mph_gait_id/` |

`MPH_GAIT_ID_SETTINGS` 可指定不同的語言設定檔路徑；版面檔使用相同目錄，
在檔名後加 `_layout`。例如 `test-settings.json` 對應 `test-settings_layout.json`，
可用於隔離測試安裝。預設不會加入 Git。格式錯誤、過大或版本不支援時退回
預設版面；使用原子置換寫入，失敗會提示且不影響 Gallery。

只保存指定的介面欄位，不保存搜尋字串、人物選取、來源／權重路徑、
辨識設定、攝影機狀態或註冊 session，也不自動啟動設備。
換螢幕後將視窗限制在主要螢幕內；支援的平台會恢復最大化狀態。
螢幕較小時，最小可視區域與表頭寬度優先於精確還原。
尚未開啟的分頁保留待還原比例，首次開啟時再套用。
強制結束程式可能遺失本次版面調整，不表示已保存的 Gallery 遺失。

## 基本與進階設定

即時頁保留來源、人物偵測器類型、模型／權重、T、stride 與運算裝置等常用設定。
偵測器權重路徑、較少調整的辨識與 Replay 參數可收合，離線的未知人物判定設定
也可收合。收合只控制顯示，不改變參數。

即時檢查摘要仍顯示偵測器與設定狀態；「查看設定」會展開並捲動到對應區域。
擷取、停止及待檢視期間保留原有設定鎖定，展開不會解除鎖定。

## Gallery 與來源搜尋排序

- 在目前 Gallery scope 或來源清單中，以人物 ID／名稱做不分大小寫的部分搜尋。
- 點表頭排序，再點一次反向；數量／大小採數字排序，ID 使用自然順序，例如 P2 在 P10 前。
- 狀態列顯示目前筆數／總筆數、選取數、排序欄位與方向。
- 搜尋欄按 Escape 或「清除」移除搜尋條件。
- 同一次執行中的重新整理／語言切換保留搜尋排序，重開程式不自動恢復搜尋。

排序不改變資料 ID 或操作對象。當搜尋隱藏已選取列時，清除該列的選取，
不讓看不到的來源繼續被匯出、刪除或註冊。清除搜尋也不自動重新勾選。
模型、T 與前處理版本的既有範圍限制，以及刪除／匯入確認不變。
辨識候選表不提供任意排序，繼續呈現模型的實際排名。

## 預覽操作

離線、來源與即時點雲預覽共用旋轉、鏡像、移動、重設圖示與雙語提示。
滑鼠停留或鍵盤移入按鈕可查看名稱。來源與離線播放具有一致的上一幀、
下一幀、播放操作，並保留幀位置顯示。
即時視角工具可展開，縮放仍位於預覽頂端；來源頁保留縮放滑桿。

所有預覽操作都不改寫點雲、模型輸入或特徵。即時／來源保留固定物理視野，
離線保留原本的自動適配顯示。小視窗將影像等比例縮入實際可用區域，
不再因最小渲染尺寸被裁掉。永久刪除操作使用不同樣式，仍需要既有確認與備份。
優先使用已安裝的繁體中文介面字型，表格列高依目前字型高度調整。
即時／來源的點數資訊留在影像外，不再疊字遮擋預覽。

## Local 驗收

先備份完整 `data/`，使用測試人物操作。

1. 修改視窗、分隔條、欄寬、進階收合與語言；正常關閉再開啟，確認版面恢復，
   但不自動啟動 Kinect 或恢復人物註冊。
2. 改 T／threshold 後重設版面，確認參數不變。測試 980x640、最大化及 Windows 125%／150%。
3. 搜尋、數字排序、ID 排序、重新整理與中英文切換；核對操作仍指向原人物／來源 UUID。
   隱藏選取來源後，確認其不再包含於匯出或多模型註冊。
4. 輸入錯誤設定／偵測器路徑後收合，用摘要的「查看設定」定位。
   執行期間展開區域不可讓已鎖定的參數變成可編輯。
5. 播放來源，旋轉、鏡像、移動、縮放、重設；同一幀重設後應恢復原視角。
   檢查中英文提示與小視窗中的 RGB／點雲完整顯示。
6. 重測引導註冊／Review／儲存、辨識、多模型來源註冊、來源與 Gallery 移轉、
   測試人物刪除，確認既有流程不變。

```bash
python -m unittest discover -s mph_gait_id/tests -q
python -m unittest discover -s scripts/tests -q
python scripts/validate_release.py
```

GUI 測試需要圖形顯示環境。Server 使用暫存資料庫與合成點雲驗證；
Windows 字型／縮放與 Azure Kinect 設備行為仍需 Local 實機驗證。
