# 即時點雲步態身分辨識系統 UI 使用說明

## 四個頁面

- 「離線」：用既有 `clear_data_*.npy` 點雲序列進行註冊或辨識。
- 「即時」：連接 Azure Kinect，執行偵測、人體點雲預覽、引導式註冊與辨識。
- 「Gallery 管理」：直接查看與管理註冊人物、sessions、passes 與來源。
- 「即時效率測試」：直接以 Kinect 比較完整 pipeline 與不同點雲模型的效率，只保存數值報告。

離線頁的「開啟離線批次」會留在離線工作；註冊名單與資料管理集中在 Gallery 管理頁，避免即時操作和資料維護混在一起。
跨電腦搬移已註冊特徵時，使用該頁的「匯出全部 Gallery」與「匯入 Gallery」。
模型相容性、人物衝突與備份操作請參閱
[Gallery 匯出／匯入](GALLERY_TRANSFER_zh.md)。

## 畫面

即時預覽固定為兩區：RGB 人物偵測與人體點雲。點雲視圖不會因點數或人物大小改變 widget 尺寸，可用滑鼠手動縮放。RGB 區的「在 RGB 顯示人體點雲」可即時開關綠色疊圖；它顯示深度與前景過濾後的點雲位置，只影響預覽，不會改變模型輸入。系統沒有額外的步態影像輸入畫面。

## 人物分割選擇

- YOLO：速度快，但人物框內的近距離背景可能保留。
- YOLO-Seg：通常是即時模式的首選，速度與遮罩品質較平衡。
- SAM：使用 YOLO 人框提示 SAM 細分人物，不是只靠 SAM 搜尋所有物件；遮罩較細但 FPS 通常最低。

## 引導式註冊

目前模型只支援正面訓練條件，因此介面只提供「正面／面向相機」。在人開始正面行走前按開始，完成後立即按結束；轉身和背面回程都放在 pass 之外。

檢查畫面的「納入註冊」用來決定哪些 pass 寫進 Gallery。有 embedding 的 pass 都可人工勾選；自動移動方向只顯示警告，不再鎖死選項。沒有 embedding 或已捨棄的 pass 仍不可選。

「多人時仍允許註冊」預設開啟，行為和舊版相同：偵測到多人仍繼續，但只收集主要人物。若背景人員可能走到主要人物前方，建議取消勾選，改成多人時暫停收集。

檢查畫面允許勾選任何有 embedding 且未捨棄的 pass；品質警告需要再次確認。按完成後，必須看到成功訊息及寫入 clip 數才算真正註冊完成；之後可立刻到 Gallery 管理頁確認。

## 即時效率測試

第四頁不顯示影像，避免 UI 繪圖干擾效能比較。選好模型後按開始，取得第一個有效人體點雲才會進入暖機，暖機後自動正式測量並保存純數值 JSON。

靜坐可比較 Kinect、偵測、點雲前處理、模型 encode 與 Gallery match 的速度，但不能據此判斷辨識準確率。比較 MPH-Gait ID 與 LidarGait++ 時，偵測器、Device、stride、人物位置和 Gallery 規模必須保持一致。完整流程見 `PERFORMANCE_BENCHMARK_GUIDE_zh.md`。

## 「點雲處理版本」是什麼

它表示「這批點雲是用哪一套前景過濾與標準化規則產生」。例如未來若更換深度範圍或取樣規則，會得到另一個版本。不同版本不應混在同一次比對中，因此 Gallery Manager 提供此篩選。一般操作只需保留預設的「人體前景點雲 v1」。
