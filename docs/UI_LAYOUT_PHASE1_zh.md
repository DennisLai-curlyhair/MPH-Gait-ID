# UI 階段一：版面與狀態保留

## 範圍

本次是 Conference 應用程式的 Tkinter/ttk 介面改善，不變動模型、權重、
輸入格式、比對規則、相容性雜湊、資料庫結構、套件或版本號。
不需要資料遷移或重新註冊，Journal 工作目錄不受影響。

## 更新項目

- 分頁與固定控制項預留中英文寬度，表格欄位保留表頭所需空間。
- 語言切換只更新呈現，不重建頁面、不翻譯人物名稱或路徑，也不重設模型、
  門檻、註冊內容與執行中的工作。
- 切回即時／效能頁只刷新同一 bundle 的 Gallery 數量，不重新套用預設值。
  真正更換 bundle、權重雜湊或模型／輸入設定時，仍會更新對應預設值。
- 即時頁側欄可拖拉寬度；離線預覽／結果與效能設定／監看／結果區具有
  預設比例及最小可視範圍。長名稱、路徑與狀態文字依配置寬度換行。
- 狹窄視窗可捲動設定和預覽工具，結果表格支援水平／垂直捲動。
  效能頁開始、停止、匯出按鈕位於設定捲動區外。
- Gallery 刷新保留人物、同一筆實際片段及捲動位置，不以畫面列號識別片段。
  切換人物、模型或 T 不會誤選另一個範圍的同號片段。
- 來源刷新保留仍存在的多選來源、目前 pass、幀、縮放與清單位置。
  切離來源頁會暫停播放，但返回後不歸零，也不自動重新播放。
  已刪除來源會清空預覽，避免顯示過期資料。

狀態保留限於本次程式執行期間。本階段不包含重開程式後的版面記憶，
也不重設整體註冊流程。動態文字內容變長時仍可能換行並改變高度。

## Local 驗收

1. 測試 1380x860、980x640 及 Windows 125% 顯示縮放。拖拉分隔條並捲動，
   確認預覽、結果與來源移轉按鈕均可操作。
2. 自行修改模型 T、threshold、detector 權重與人物名稱，反覆切換中英文及
   五個分頁，確認設定不被還原。主動更換 bundle 時應正常套用新預設值。
3. Gallery 選取人物與片段並捲動，重新整理、切換語言，確認仍選取同一片段；
   再測試改名及刪除另一筆片段之後的選取狀態。
4. 來源頁多選資料、切換 pass、播放到中間並縮放，重新整理或離開再返回，
   確認保留播放位置且處於暫停。刪除來源後不可殘留該來源的預覽。
5. Local 接上 Azure Kinect，分別在即時辨識、註冊擷取／review、效能測試中
   切換語言，確認持續擷取且結果更新正常。硬體部分必須在 Local 驗證。
6. 用測試人物再做 Gallery／來源匯出匯入，確認衝突預覽與確認步驟維持原流程。

於專案根目錄、應用程式的環境中執行：

```bash
python -m unittest discover -s mph_gait_id/tests -q
python -m unittest discover -s scripts/tests -q
python scripts/validate_release.py
```

GUI 測試需要圖形顯示環境，沒有時會標示 skipped。自動 GUI 測試使用暫存
資料庫，不開啟攝影機、不讀寫已註冊人物。Windows 實機測試仍需另外完成。
