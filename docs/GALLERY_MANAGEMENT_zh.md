# Gallery 人物與特徵管理

[文件索引](README.md) | [English](GALLERY_MANAGEMENT.md)

先停止辨識、註冊及效率測試，並提交或放棄待檢查的註冊片段，再開啟
「Gallery 管理」。以下操作不修改模型權重或特徵編碼設定。

## 操作與範圍

| 操作 | 影響範圍 | 保留內容 |
|---|---|---|
| 修改人物名稱（所有模型） | 選取 Person ID 的顯示名稱，跨全部模型 | ID、特徵、啟停狀態與歷史報告 |
| 停用／恢復選取 pass | 選取人物、模型 key、session 與 pass | 所有特徵資料列 |
| 永久刪除選取片段 | 選取人物、模型 key、來源、session、pass、方向，含停用特徵 | 人物、其他片段與其他模型 |
| 刪除人物及全部模型特徵 | 選取人物及其全部模型的啟用／停用特徵，不受模型篩選限制 | 其他人物、模型紀錄及權重 |
| 匯出全部 Gallery／匯入 Gallery | 詳見 [Gallery 匯出／匯入](GALLERY_TRANSFER_zh.md) | 以合併方式保留本機相容資料 |

離線頁的「停用該人物於目前權重的全部特徵」只是停用，不是永久刪除，
也不影響其他模型 Bundle。永久刪除需在 Gallery 管理頁操作。

「顯示所有人物（跨模型，含無特徵者）」只擴大左側人物表範圍。頂部統計
與右側片段仍依模型、Frame 長度與點雲處理版本篩選。左右表格有水平捲軸，
可查看完整來源與其他欄位；匯入來源識別碼不代表可播放的媒體路徑。

## 改名與刪除流程

1. 選取人物；找不到時勾選「顯示所有人物」。
2. 改名時輸入新的顯示名稱，Person ID 不變。後續註冊須使用新名稱；已填入
   的註冊欄位若仍顯示舊名稱，請自行更新。
3. 刪除片段時，在右表選取一列，確認來源、session、pass、方向及啟停數量。
4. 完整刪除人物時，必須輸入大小寫完全相符的 Person ID，且會跨所有模型。
5. 完成後核對特徵數與訊息中的修改前備份位置。

沒有 session／pass ID 的舊資料可以按來源列永久刪除；停用／恢復 pass
仍需要兩個 ID。刪除最後一段不會刪除人物，系統會自動顯示所有人物，方便
管理空的人物紀錄。完整刪除後雖可重用 ID，不同人物仍建議用新 ID，以免
與保留的歷史報告混淆。

## 備份與復原

每次改名或永久刪除前，都用 SQLite backup API 備份整份已提交的資料庫，
包含 WAL 內容，並檢查完整性。位置在目前設定資料庫旁：

```text
data/backups/gallery_before_edit_<timestamp>_<unique-id>.sqlite3
```

確認後資料若變動，操作會取消。備份失敗不修改資料；寫入失敗會回滾全部
變更，包含匯入識別紀錄。備份及刪除目前同步執行，大型資料庫可能短暫等待，
請勿強制關閉應用程式。

「永久刪除」只刪目前資料庫中的資料列，不刪原始點雲、sessions、歷史報告、
匯出包、既有備份或模型權重，**不是個資安全抹除功能**。備份含姓名與生物特徵，
未加密、不自動清理，且排除於 Git。請管理存取權與保留期限。

目前沒有一鍵復原。還原整庫前須關閉所有資料庫連線，另存現況資料庫與其
sidecar 檔案，再還原修改前 SQLite 備份；這也會回復該快照之後的新增註冊。
重新匯入舊 `.mphgallery` 不是復原操作。

## 與匯入／匯出的配合

- 改名不改可攜式身分識別碼；匯入舊包保留本機新名稱，不恢復停用特徵。
- 永久刪除片段會保留已知識別碼的刪除紀錄。重匯舊包時略過這些特徵並顯示
  數量，其餘資料仍可匯入。
- 舊包中的已刪人物顯示「已永久刪除（略過）」，不可重新對應至其他 ID，
  也不會因相同 ID 被新人物重用而自動合併。
- 新人物重用顯示 ID 後，匯出時會取得不同的可攜式識別碼。在仍保留舊人物
  的另一台電腦上會出現 ID 衝突，需要明確處理，不會自動視為同一人。
- 刪除紀錄只在本機保存，不是跨電腦同步刪除指令，也不撤銷舊匯出包與備份。
  沒有這些紀錄的全新電腦仍能匯入舊包。
- 直接修改 SQLite 或使用重新產生身分識別碼的第三方匯入包，不屬於此保護
  流程；請使用管理介面並保留相關 provenance 資料表。

匯出格式仍為 version 1，既有 embedding、model key 與權重相容條件不變。
第一次使用管理或匯入／匯出時會建立額外的本機管理紀錄表，不會自動改名
或刪除既有人物。

## 驗證

在專案根目錄執行：

```bash
python -m unittest discover -s mph_gait_id/tests -v
python -m unittest discover -s scripts/tests -v
```

測試使用臨時資料庫與合成特徵。沒有圖形顯示環境時，Tk 視窗測試會跳過。
部署前請在有桌面環境的電腦使用獨立測試資料庫確認中英介面及實際裝置流程。
